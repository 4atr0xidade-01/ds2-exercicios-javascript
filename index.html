Fundamentos da Web

Página estática

Uma página estática é uma página que possui um conteúdo fixo. Ou seja, quando uma pessoa acessa a página, ela recebe praticamente o mesmo conteúdo que está salvo no servidor.

Exemplo: uma página simples de uma empresa, mostrando informações como endereço, telefone e horário de funcionamento.

Página dinâmica

Uma página dinâmica é uma página que pode mudar o conteúdo de acordo com o usuário, com alguma informação ou com uma ação feita na página. Para isso, normalmente existe algum processamento no servidor.

Exemplo: um site de uma loja online, onde os produtos mostrados podem mudar de acordo com a pesquisa ou com os dados do usuário.

Caminho de uma requisição

  1. O usuário digita um endereço e acessa uma página pelo navegador.
  2. O navegador envia uma requisição para o servidor.
  3. O servidor recebe essa requisição.
  4. O servidor procura ou processa as informações necessárias.
  5. O servidor envia uma resposta de volta para o navegador.
  6. O navegador recebe a resposta e mostra a página para o usuário.
